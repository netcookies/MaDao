# Learnings

Category: `learning`

Use this file to capture durable lessons discovered during execution.

## Entry Format

```text
- Date: YYYY-MM-DD
  Source: file:line | commit | workflow session
  Category: learning | debug | arch | coding | quality
  Summary: short statement of the learning
  Impact: why it matters for future work
```

## Guidance

- Prefer concrete, reusable lessons over raw session notes.
- Record cross-layer pitfalls, provider quirks, and workflow constraints.
- Link every learning to a source anchor.
- Promote repeated patterns into dedicated spec files when they become conventions.
